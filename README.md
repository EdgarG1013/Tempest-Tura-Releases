## Descripción

**Tempest-Tura** es una plataforma de monitoreo climático y gestión de riesgos comunitarios. Combina datos meteorológicos en tiempo real con reportes ciudadanos para que la comunidad vea y emita alertas ante eventos como inundaciones o derrumbes.


## Gestión del proyecto

El proyecto se desarrolla con Scrum: el trabajo se organiza en sprints y las historias de usuario se gestionan en Jira.
